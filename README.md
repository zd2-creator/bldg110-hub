# bldg110-hub — עמוד ריכוז הטפסים של ועד בית בניין 110

דשבורד שמרכז את כל הטפסים/ההצבעות של הבניין ומציג את מצבם בזמן אמת.
מוגן באותה סיסמת שער כמו הטפסים (GATE_ALL ב-Script Properties).

**להוספת טופס חדש:** שורה בראש מערך `FORMS` ב-`index.html` (הכי חדש למעלה).

**מצב ניהול:** כפתור 🔑 בראש העמוד חושף קישורי אדמין לכל טופס (נשמר במכשיר).
הוא רק מגלה קישורים — כל מסך אדמין עדיין דורש את סיסמת האדמין.
